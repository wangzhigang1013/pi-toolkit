# 表格对齐表格式 — 写法规范

适用于**多标签分类体系**。范式来自「顾虑标签 Principle 对齐表」。

空白模板见 `assets/template-table.md`，本文件讲每个字段**怎么填**。

---

## 整体结构

```
# <体系名> Principle 对齐表

## 需要对齐的标签 Principle      ← 主表，每行一个标签
<主表：备注 | 标签内容(层级路径) | Principle(定义/边界/对比) | 举例>

## <维度> 类标签速查对比          ← 若干张速查表，按混淆簇分组
...

---
版本 / 日期 / 定版签字
```

## 主表四列怎么填

### 第 1 列：备注
只填 `易混淆` 或留空。判断标准：这个标签和别的标签是否容易串（触发词重叠、语义相近、标签树相邻）。易混淆的必标，提醒标注者小心。也可放一句最易错的提示语。

### 第 2 列：标签内容（标签层级路径）
- 写**完整层级路径**，用 `→` 连接：`观望顾虑→现在买车有顾虑→对优惠政策有顾虑`。
- 路径让标注者知道这个标签在树里的位置，相邻路径的标签就是消歧重点。
- 标签名下方可补一行**口语化判别提示**（如 `"感觉贵" = 顾虑超过购车预算`），帮标注者快速对应。

### 第 3 列：Principle（定义、边界、对比 label）— 最重要的列
固定按这个顺序写，缺一不可：

1. **定义：** 一句话讲清在判断什么。要点明这个标签**聚焦的维度**（如"聚焦资金的时间维度和流动性"），维度是和邻居划界的根据。
2. **（可选）范围 / 识别层级原则：** 多级标签必写——什么时候识别到几级、什么条件下停在上级。如"若客户明确说出预算区间且有负向语义，识别到对应四级"。
3. **触发词：** 列具体词，逗号分隔。要给真实词，不要写"相关表述"。
4. **边界：**
   - `✅ 包括：` 列正例情形（情形，不是例句）。
   - `❌ 不包括：` 每条都带去向 `（→ 应归到的标签）`。**这是全表最容易漏、也最关键的地方。**
5. **对比标签：**（易混淆标签必写）`→ 标签A：和本标签的区别 → 标签B：区别`。

### 第 4 列：举例
- ✅ 正例和 ❌ 反例**成对**给，对比鲜明。
- 反例后标去向：`❌ "我预算就30万，超了。"（→ 顾虑超过购车预算）`。
- 例句用**真实对话风格**口语，不要造书面句。
- 涉及层级识别的，例句后标识别结果：`✅ "我预算就30万，L8得38万。"（识别至：预算30w~40w）`。
- 需额外抽取实体的，例句后标抽取结果：`✅ "还在和问界M9纠结。"→ 对比问界 M9`。

## 速查对比表怎么建

主表之后，按**混淆簇**建若干张极简速查表，给标注者快速查阅。一张表对应一组易混淆标签。两种列式：

**情境式**（一句话情境 → 标签）：
```
| 核心情境 | 正确标签 |
| --- | --- |
| 车价超出我的预算上限 | 顾虑超过购车预算 |
| 我的钱还没凑齐/款未到账 | 顾虑钱没到位 |
```

**带路径式**（语义 → 标签 → 路径，适合需要强调归属路径的）：
```
| 政策类型 | 正确标签 | 所属路径 |
| --- | --- | --- |
| 国家新能源整体政策 | 顾虑缺乏政策支持 | 能源形式顾虑→对增程/混动有顾虑 |
```

建表方法：把方法论里识别出的"看起来都像、实则不同维度"的簇，每簇一张表，把最易错的对照关系压成一行一条。

## 常见错误
- ❌ 负例不写去向 → 标注遇到负例不知道改标哪个。
- 触发词写"等相关表述"→ 等于没写。
- 多级标签不写识别层级规则 → 标到几级全凭感觉。
- 例句是造的书面句 → 和真实语料对不上。
